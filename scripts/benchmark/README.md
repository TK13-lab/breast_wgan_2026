# Benchmarks

Benchmark scripts used alongside the breast WGAN paper workflow.

- `01_revision_baseline_signature_benchmark.py`: GAN rank vs simpler ranking and PCA baselines
- `02_revision_scvi_latent_benchmark.py`: optional scVI latent baseline
- `03_revision_method_family_comparison_plot.py`: method-family comparison plot
- `04_revision_patient_pair_equal_budget_benchmark.py`: patient-pair equal-budget benchmark
- `05_revision_latent_patient_pair_benchmark.py`: patient-pair latent benchmark for `scvi` or `scgen`
- `06_revision_statistical_reporting_summary.py`: summary tables for reporting
